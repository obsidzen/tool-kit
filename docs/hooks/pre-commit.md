# pre-commit — 커밋 전 빠른 검사

## 만든 이유

비밀과 큰 파일을 이력에 넣기 전에 검사하면서 커밋마다 Go 전체 빌드·테스트를 반복하지 않기 위해 적용했다.

## 역할과 범위

prek 내장 파일명·5 MiB 크기·개인키 검사와 Gitleaks staged 탐지를 실행한다. 자동 수정·stage는 수행하지 않는다.

## 구현과 연결

[진입점](../../.githooks/pre-commit), [검사 설정](../../.pre-commit-config.yaml), [도구 버전](../../mise.toml), [설정 명령](../../scripts/setup.sh)을 사용한다.

## 검증과 한계

일반 입력, 비밀·대용량 차단과 부분 스테이징 보존을 임시 저장소에서 확인했다. 비밀 탐지는 완전하지 않으며 도구 누락을 성공으로 간주하지 않는다. 같은 index를 여러 에이전트가 동시에 수정하는 구성은 보장하지 않는다.
